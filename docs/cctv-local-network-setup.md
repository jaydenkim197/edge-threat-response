# CCTV–Orin 동일 네트워크 연결 기록

2026-11-05, P430과 Jetson Orin Nano를 전용 공유기의 같은 LAN에 연결하고 **실제 CCTV 영상 수신·YOLO26n 추론**을 확인했다. 물리 구성은 사용자 인수인계, 아래 IP·포트·영상 처리 결과는 접속 후 실측 기준이다.

## 연결 구성

```text
N604SR 공유기 (192.168.0.1)
 ├─ LAN ─────────────── Jetson Orin Nano (192.168.0.10)
 ├─ LAN → PoE 인젝터 → Reolink P430     (192.168.0.4)
 └─ Wi-Fi ──────────── 개발 노트북      (192.168.0.6)
```

PoE 인젝터의 데이터 입력은 공유기 LAN에, PoE 출력은 CCTV에 연결했다. Orin은 공유기 LAN에 직접 연결했다. 노트북은 같은 공유기 Wi-Fi `SSAMBBONG`으로 접속했다.

| 장비 | 검증 당시 설정 |
|---|---|
| 공유기 | N604SR, LAN `192.168.0.1/24` |
| Orin | 유선 `enP8p1s0`, `192.168.0.10/24` |
| CCTV | P430, `192.168.0.4`, DHCP |
| 노트북 | Wi-Fi, `192.168.0.6` |

주소는 DHCP에 따라 바뀔 수 있으므로 재연결 시 공유기 장치 목록에서 확인한다. 노트북이 다른 Wi-Fi로 이동하면 위 LAN 주소로 직접 접속되지 않을 수 있다.

## 카메라 설정과 접속

1. Reolink Client에서 P430 설정 → **Network → Advanced → Server Settings**로 이동한다.
2. **RTSP 554 / ONVIF 8000**을 활성화하고 **Save**를 누른다. 다시 열어 설정 유지를 확인한다. 체크만 하고 저장하지 않았을 때는 연결이 거부됐다.
3. RTSP 인증에는 **카메라 자체 계정**을 사용한다. Orin의 비공개 `data/local/p430-connection.json`에 저장하며 비밀번호는 Git에 넣지 않는다.
4. 같은 LAN에서 `ssh jorin@192.168.0.10`으로 Orin에 접속한다. 카메라 포트는 다음 명령으로 확인한다.

```bash
timeout 5 bash -c 'echo > /dev/tcp/192.168.0.4/554' && echo "RTSP OPEN" || echo "RTSP CLOSED"
```

## 확인 결과

- Orin→CCTV의 유선 경로·장비 MAC 일치·ping 통과. 카메라 `554/8000/9000` 포트와 RTSP 인증 `200 OK`를 확인했다.
- 서브스트림 **640×360**, 메인스트림 **3840×2160**을 디코딩했다. 처음 여는 데 약6.2초가 걸려 수신기의 초기 제한을5→20초로 수정했다. 읽기 제한은5초다.
- **COCO YOLO26n person + RAW-R1-n knife**, 입력640/FP32로 두 스트림을 각각 **300프레임 정상 처리**했다. B3 판단·metadata·snapshot·mock 경보를 확인했다.
- Orin 모니터에서 실시간 탐지 박스 표시를 확인했고, 사용자도 움직이는 화면을 확인했다. 시연 창은 **Q/Esc**로 종료한다.

영상은 **CCTV→로컬 LAN→Orin**으로 직접 전달했다. 개발 당시 인터넷도 연결돼 있었으며, **공유기 WAN 제거·재부팅 자동 복구·물리 GPIO·실제 탐지 정확도는 아직 검증하지 않았다.**
