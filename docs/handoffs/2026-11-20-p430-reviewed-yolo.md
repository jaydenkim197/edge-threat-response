## 개발2에서 이어갈 작업

1. PC13에서 위 경로의 manifest와 검증 결과를 확인한 뒤 T1 데이터 구성에 사용한다. 이전 701장 스냅샷과 두 점검 팩은 이 버전과 함께 합치지 않는다.
2. 분할 단위는 `manifest.jsonl`의 `session`과 `source_video_sha256`이다. 세션을 프레임 단위로 쪼개 train/validation/test에 섞지 않는다. 이번 산출물에는 train/val/test나 YOLO `data.yaml`을 배정하지 않았다. 두 세션만으로 학습·튜닝·독립 최종 평가를 모두 만들 수 없으므로, 두 세션을 개발에 쓸 경우 별도 최종 평가 촬영분이 필요하다. 기존 보호 평가 자료도 그대로 보존한다.
3. 4K 원본에 `[960, 540, 2880, 1620)`을 적용한 데이터다. 이 데이터로 직접 재현할 평가는 동일한 중앙 크롭을 적용한다. 전체 화면이나 타일 입력의 결과는 별도로 측정한다.
4. 1,184장은 중앙 영역을 고정한 화면으로 검수했고, 717장은 당시 표시 범위가 저장되지 않은 기존 판정이다. 필요하면 manifest의 `review_scope`로 나눠 비교한다. 인계 범위는 사람 검수 기반 knife bbox이며 Holding 관계·영상 사건 정답은 별도로 준비한다.

재생성은 PC13 저장소의 `tools/export_p430_review_crops.py`에 두 촬영 루트를 `--sessions`, `p430-multibox-check-20261120`와 `p430-outlier-check-20261120` 루트를 `--review-overrides`로 넘긴다. `--require-complete`를 사용하고 `--output`에는 새 폴더를 지정한다.
