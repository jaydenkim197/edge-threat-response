# P430 타일 학습의 연구 근거와 적용 범위

2026-11-24 · [설치 환경 맞춤 학습 계획](p430-site-finetuning-plan.md)

P430 2차 개발 영상에서 칼 박스 짧은 변의 중앙값은 전체 영상을 960에 넣었을 때 8.3px였다. 중앙 1920×1080에서 768×640 타일을 잘라 640에 넣으면 같은 위치의 칼은 이론상 약 13.8px로 들어간다. 이는 letterbox 축척으로 계산한 값이다. 배경이나 가림에 사라진 영상 정보는 복원되지 않는다. 기존 가중치의 저오탐 결과가 전체 0/316에서 타일 5/316으로 변했고, 타일에서 낮은 점수 후보까지 남기면 199개가 정답과 겹쳤다. 그 결과가 타일 학습을 먼저 시도할 근거이며, 검출·경보 개선은 새 실험 대상이다. [기존 원본 비교](../reports/evaluation/p430-alternatives-2026-11-21/report.md)

| 원 논문의 접근 | P430에 적용하는 방식과 한계 |

| Akyon 외, SAHI, ICIP 2022 | 겹치는 고해상도 조각으로 학습하고 추론 결과를 원좌표로 병합했다. 드론 영상의 수치를 P430 성능으로 옮길 수는 없다. 타일을 학습 입력과 추론 입력의 두 축으로 분리한다. 고각 CCTV의 전역 문맥도 필요해 학습에 전체 화면을 섞고, Orin에선 시간 비용을 측정한다. [논문](https://arxiv.org/abs/2202.06934) |
| Singh 외, SNIPER, NeurIPS 2018 | 전체 피라미드 대신 객체와 배경이 있는 영역을 적절한 크기로 처리했다. 우리도 실제 양성 박스와 확인된 음성을 이용해 적합한 타일을 고른다. RPN 제안과 여러 영상 피라미드 구현은 현재 YOLO 학습기에서 별도 구현이 필요하다. 기존 겹침 격자와 라벨 보존 규칙으로 먼저 검증한다. [논문](https://arxiv.org/abs/1805.09300) |
| Lin 외, FPN, CVPR 2017 | 서로 다른 해상도의 특징을 결합해 소형 객체에 의미 정보가 있는 특징맵을 제공했다. 입력 축소로 이미 사라진 신호는 neck 변경만으로 돌아오지 않는다. 이번 실험에서는 같은 YOLO26n 구조를 유지해 입력 스케일의 효과를 먼저 확인한다. [논문](https://arxiv.org/abs/1612.03144) |
| Kumar 외, Fine-Tuning can Distort Pretrained Features, ICLR 2022 | 분류 전이학습에서 전체 미세조정이 사전학습 표현을 바꾸고 분포 밖 정확도를 떨어뜨릴 수 있었다. 이 프로젝트에서 1차 기존 모델의 전체 검출 87개가 통합 최고 74개로 떨어졌다는 관측은 이와 양립하지만 원인 증명은 아니다. 동일 데이터에서 backbone 파라미터와 BN 통계를 고정한 조건을 추가해 검증한다. 새 촬영 환경에서 backbone 자체의 적응이 중요하면 전체 미세조정이 더 좋을 수도 있다. [논문](https://arxiv.org/abs/2202.10054) |
| Chen 외, Domain Adaptive Faster R-CNN, CVPR 2018 | 이미지와 객체 수준의 도메인 차이를 별도 정렬했다. P430은 승인된 supervised target 라벨과 이미 학습한 source가 있다. 같은 장면에서 원래 특징을 보존할 수 있도록 실사와 외부 CCTV를 함께 샘플링한다. 도메인 판별기를 도입하는 논문 방법은 detector와 학습 목표를 동시에 바꾸므로 비교의 첫 항에는 넣지 않는다. 50/30/20은 문헌의 최적비가 아닌 개발 기준점이다. [논문](https://arxiv.org/abs/1803.03243) |
| Beery 외, Recognition in Terra Incognita, ECCV 2018 | 고정 카메라의 익숙한 위치와 새 위치를 구분해 평가했다. 이번 요구는 고정 장소 성능이므로 같은 장소의 다른 촬영을 허용하되 같은 원본·테이크·인접 프레임이 경계를 넘지 않게 한다. 동영상 두 편 내부 분할의 개발 점수는 새 장소 일반화 증거가 아니다. [논문](https://arxiv.org/abs/1807.04975) |
| Shrivastava 외, OHEM, CVPR 2016 | 검출기에서 높은 손실을 보이는 예제를 선택했다. 기존 일반 혼동 음성 재표집의 개선이 일관되지 않았으므로, 다음 단계는 설치 장소에서 반복되는 실제 오탐을 사람이 확인해 채택한다. 온라인 손실 기반 OHEM 전체를 구현하는 대신 음성 추출 예산과 양성 목록을 유지해 장소 특화 음성만의 효과를 비교한다. [논문](https://arxiv.org/abs/1604.03540) |
| Zhang 외, ByteTrack, ECCV 2022 | 낮은 점수 박스를 기존 궤적과 연관시켜 놓친 객체를 복구했다. 겹치는 아이디어는 약한 후보를 일찍 버리지 않는 것이다. ByteTrack의 ID 추적 도입은 별개의 변수다. 현재 B0~B4의 공간·관계·시간 판단에서 후보 점수를 조정하고, 사건 단위 오경보와 지연으로 평가한다. [논문](https://arxiv.org/abs/2110.06864) |

타일 실험의 가설은 같은 부모와 업데이트 수에서 입력 축척이 작은 칼의 정검출을 높인다는 것이다. 백본 실험의 가설은 부분 학습이 기존 특징의 손실을 줄인다는 것이다. 둘 다 열어 두기 위해 전체/타일 × 전체 학습/백본 동결 네 조합을 같은 데이터로 실행한다. 각 가중치는 전체 화면과 타일 추론에서 각각 평가한다. 검출 점수와 임계값은 tune에서 비교하고 고정된 검출점을 dev-check에 전송한다. AP, 작은 칼·전체 recall과 음성 FP를 기록하며, 별도 시간 정답이 확보된 개발 영상에서 사건 지표를 검증한다.

보호된 최종 편집본은 사용자가 별도 11/24 촬영분이라고 확인했다. 편집본의 파일 해시만 보호 목록에 넣었고 영상과 정답은 학습 PC에 복사하지 않는다. 원본 녹화 SHA 및 편집 컷의 원본 매핑은 독립 최종 평가 전에 보강할 수 있는 검증 근거다.
