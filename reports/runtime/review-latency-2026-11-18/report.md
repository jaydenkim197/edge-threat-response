# 검수 사이트 전송량 개선

2026-11-18. 코드 `a2c5f03`를 PC13 검수 서비스에 배포했다. 기본 화면에 쓰는 1920px JPEG를 생성하고, 확대·박스 수정·4K 보기에서 원본을 불러온다. 모바일에서 숨겨진 이동 목록 985개를 판정 때마다 다시 만들던 작업도 생략했다.

| --- | ---: | ---: | ---: | ---: |

전체 985장 기준 1,681,848,854바이트에서 426,503,674바이트로 줄었다. 단말은 현재 개발 노트북이며 HTTPS 응답을 끝까지 읽은 시간이다. HTTP 신규 연결, 당시 네트워크 조건을 포함한다. 실제 휴대폰망이나 화면 표시까지 걸리는 시간을 측정한 값은 아니다. 개선 전 PC13 내부의 이미지 응답은 두 표본에서 2.2ms·21.7ms, 목록 API는 34.4ms였다. GPU 부하보다 이미지 전송량과 단말 처리량을 우선 개선했다.

미리보기는 source pack hash로 원본 팩과 연결한다. 원본 크기는 3840×2160, 미리보기는 1920×1080이며 SVG와 저장 박스는 원본 좌표계를 쓴다. 원본 경로와 메타데이터는 그대로 제공한다. 미리보기 접근도 기존 인증 경계를 적용하고 관련 파일 경로를 카탈로그에 노출하지 않는다.

관련 테스트 48개 통과. 격리 390px Chromium에서 미리보기와 4K 전환, 박스 추가·저장, 제외, 재접속과 화면 넘침을 확인했다. 운영 HTTPS에서 원본·미리보기 크기와 응답을 대조했다. 배포 전후 DB 테이블 해시가 일치했으며 백업은 PC13 `data/review/team-server/backups/before-review-latency-20261118`에 있다. 실제 휴대폰 사용감은 추가 확인이 필요하다.
