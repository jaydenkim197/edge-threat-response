## 완료된 Track A 실험

PC11/12의 D1 학습 재현은 seed 3408/3409만 바꿔 D0 초기값, 12 epoch×8,192 추출, batch 8, 입력 640, 전체 학습, 같은 혼합 타일·약증강 설정을 사용했다. 두 실행 모두 12 epoch와 평가 결과를 확인했다. tune에서 각 모드의 임계값과 checkpoint를 선택하고 287장 개발 확인 구간에 적용했다. 두 번 모두 1 epoch 이후의 EMA가 선택됐으나 음성 프레임 오탐이 늘었다. 결과는 독립 최종 시험 전의 개발 결과다.

| 조건 | 입력 | 작은 칼 TP / 58 | 전체 TP / 140 | 음성 오탐 / 147 | 오탐 박스 | AP50 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| PC13 D1 | 6타일 640 | 47 | 81 | 0 | 23 | 61.82% |
| PC11 seed 3408, 첫 epoch EMA | 6타일 640 | 40 | 77 | 4 | 23 | 62.35% |
| PC12 seed 3409, 첫 epoch EMA | 6타일 640 | 50 | 91 | 3 | 36 | 67.07% |
| 같은 PC13 D1 | 전체 960 | 10 | 37 | 3 | 34 | 30.28% |
| 같은 PC13 D1 | 전체 1280 | 25 | 59 | 4 | 42 | 44.16% |
| 같은 PC13 D1 | 전체 960 + 6타일 640 | 47 | 80 | 1 | 29 | 58.17% |

이번 운영점에서는 기존 D1 6타일을 비교 기준으로 유지한다. 결합 방식은 작은 칼 TP가 같고 전체 TP가 1개 감소했다. 전체 화면 1280은 960보다 나았지만 6타일에 미치지 못했다. 저점수 예측은 후속 오류 분석용으로 보존했다. 최초 진단이 로컬 `pycocotools` import 경로 때문에 실패했고, 이전 평가와 같은 의존성 경로를 지정한 새 시도에서 tune 298장과 dev-check 287장 모두 완료했다.

## 착수한 후속 실험

| 실행 장비 | 작업 | 저장 위치의 run ID |
| --- | --- | --- |
| PC11 | Track A · COCO 초기 YOLO26n·640 | `p430-phase2-n-20261126-v1` |
| PC14 | Track A · COCO 초기 YOLO26s·640 | `p430-phase2-s-20261126-v1` |
| PC12 | Track A · COCO 초기 YOLO26m·640 | `p430-phase2-m-20261126-v1` |
| PC13 | Track B · ALT-07 native 타일 vs bicubic/Lanczos | `p430-phase2-20261126-v1/b-alt07-interpolation` |
| PC13 | Track B · ALT-12 RGB 대조 vs L채널 CLAHE | `p430-phase2-20261126-v1/b-alt12-clahe` |

n/s/m은 같은 PyTorch·Ultralytics 버전과 3060 계열에서 seed 3407, FP32, 640·batch 8, 같은 source split·draw·학습률 예산을 사용한다. 연구실 SSH가 연결을 거부해 Windows PC로 옮겼으며, 실제 onset과 첫 CUDA 배치를 확인했다. m은 PC12에서 첫 배치 약 10 GiB를 썼다. 이후 OOM이면 설정을 유지해 여유 있는 3090으로 넘긴다. PC13의 ALT-07은 이미 확보한 동일 D1과 개발 프레임만 사용한다. 보간 시험은 별도의 탐지기 학습과 구분한다.

ALT-07은 종료 코드 0으로 끝났다. native의 작은 칼 47/58, 전체 81/140, 음성 오탐 0/147 대비 bicubic은 49/58, 87/140, 1/147이고 Lanczos는 50/58, 92/140, 1/147이었다. 전체 예측 오탐 박스는 각각 23/18/24개다. 2× 축소 및 복원을 적용한 개발 진단이며 독립 영상, 다른 촬영 환경, Orin 처리량의 증거가 아니다. ALT-12는 별도 실행으로 시작했다.

PC13에서 기존 개발 계획이 지정한 image/label·타일·가중치·보호 해시 메타데이터 **34,022개**를 검증해 3,465,840,640 bytes 아카이브를 만들었다. Windows 중계 호스트까지 수신하고 SHA-256 `5795a5bd49414d42da0b8f4e159a8abeae24cc9de6ef61eda4b99493f20b94d3`가 일치함을 확인했다. 보호된 11/24 독립 평가 영상과 파생 프레임·정답은 실험과 전송 묶음에서 제외했다. VPN은 Disconnected였고 기존 프로필 재접속에서 645 인증 오류가 발생했다. 연구실 서버 수신·재해시·장기 실행은 접속 복구 후 확인한다.

11/26에 독립 원격 실행은 확인했다. 통합 자동 재배정은 `PLANNED`, 타일 오류 분석·B의 추가 실험은 [선행 조건](../../../docs/p430-track-b-alternative-detection-plan.md) 대기다. Track C 학습은 승인된 실제 Holding 입력이 필요하다. 소스 실행기와 아카이브·가중치 해시는 각 run의 `release.json`과 evidence에 보관한다.
