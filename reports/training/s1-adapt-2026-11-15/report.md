## 학습 조건과 분할

- 공통 RTX 3060, PyTorch 2.6.0+cu124, Ultralytics 8.4.152, FP32, batch 8, AdamW, 초기 LR 0.00025, 약한 색상·크기 증강, mosaic 0. 각 epoch에 2,144장 추출, 양성 1,184장과 음성 960장, 268 배치. 초기 S1 SHA-256은 `2ac5c5bb112886c1e4e7c7e5a3d68579f9ad3ac029d71d86a5397ae4bad2e358`이다.
- 기존 M2 train에서 출처·양음성 비율에 맞춰 뽑은 공통 1,792장에 실험군 CCTV 양성 160장 추출과 음성 192장을 더했다. 검수 CCTV 양성은 고유 120장을 기본으로 사용했다. 작은 칼 양성은 640 기준 박스 짧은 변 16px 미만으로 정의했고 PC11·PC14의 33회에서 PC12의 67회로 늘렸다. PC14는 학습 측 검수 음성 1,015장을 이전 혼합 모델로 추론한 뒤 높은 점수 순으로 192장을 선별했다. 그중 17장은 confidence 0.25 이상이며, 영상 그룹당 최대 6장이다. 공개 실사 대조군의 추가 352장은 고유이고 CCTV군의 추가 352장 중 고유는 312장이다.
- CCTV 1,406장은 기존 학습용으로 추출된 검수 자료다. 원본 영상 SHA, source ID, YouTube ID, 프레임 SHA 및 종횡비 필터를 적용한 dHash로 연결된 그룹을 만들었다. 37그룹 271장(칼 정답 41개, 작은 칼 6개)을 개발 튜닝으로 분리했고 나머지 151그룹에서 학습 표본을 뽑았다. 기존 보호 val/test는 각각 1,423건이며 기존 7개 개발 평가셋과 함께 보존했다. 각 PC의 실제 입력 해시와 튜닝 이미지 순서를 확인했다. 확인하지 못한 다른 편집본이 같은 장면을 담았을 수 있다. 새 튜닝셋은 이전 PC13 혼합 모델 학습에 사용된 영상에서 나왔으므로 해당 혼합 모델과의 직접 비교에는 기존 개발 평가셋을 사용한다.

## 검증과 모델 선택

각 PC에서 GPU lock, 입력 해시, 로더의 추출 횟수와 첫 epoch 결과를 확인했다. PC13에서 실제 S1 가중치로 양성·음성 2개 입력의 예측 저장과 10개 confidence 지표 계산을 확인했고, 기존 학습·평가 관련 단위테스트 32개가 통과했다. 운영용 실행기와 각 실행의 JSON 상태, 설정, 튜닝 예측은 각 PC의 `C:\Class6\edge-threat-response\runs\s1-adapt-20261115-v1`에 보관한다. 입력 계획 SHA-256은 `7b1097509636955d95361b967e36e4e2edfabe7bf1ef64b0beb147234b2bd8b6`이고, 실행기 SHA-256은 `154c7132afb1d162cb61db29ffcb833dfa665d889a0f0896f2c9279afe92673f`다. 학습 결과는 `runs/training/<run-id>`에 저장된다.

완료 후 각 실행의 best와 last를 같은 960 입력으로 튜닝셋에 자동 추론한다. confidence 0.05~0.50에서 작은 칼 TP와 전체 TP/FP, precision·recall·F1을 비교한다. 기존 S1과 혼합 모델도 포함해 공통 7개 개발셋을 평가하고, 실제 CCTV 83장에서 비슷한 오탐 수로 더 많은 칼을 맞히는 후보를 우선한다. 결과가 비슷하면 공개 실사 성능 저하와 Orin 구동 비용을 확인한다. 최종 성능 검증에는 모델·confidence 선정에 쓰지 않은 촬영 세션을 사용해야 한다. 현재 확인 범위는 본 학습 4건 시작 및 추가 2건 등록이다.
