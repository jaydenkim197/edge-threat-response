# P430 소형 칼 검출 대안 비교

2026-11-21 · 실행 ID `p430-alternatives-20261121-v1` · 개발 검증

타일 추론은 2차 촬영에서 기존 가중치의 작은 칼 검출을 0개에서 5개로 늘렸다. 2차에서 맞춘 confidence를 1차에 그대로 적용하면 칼이 없는 프레임에서 오탐이 크게 늘었다. 단순 손목 크롭은 두 촬영에서 일관된 개선이 없었다. 다음 실험은 **P430 수동 광학 줌과 Holding 관계 라벨을 포함한 대조 촬영**으로 제안한다. 기존 혼합 가중치는 비교 기준으로 보존한다.

## 비교 조건

- [T1 검증 결과](../../training/p430-t1-2026-11-20/report.md)의 정답과 예측을 재사용했다. 1차 PC13은 양성 518장·음성 331장·작은 칼 167개, 2차 PC12는 양성 383장·음성 669장·작은 칼 316개다. 각 촬영은 영상 한 편이며 표본 간격 중앙값은 1초다.
- 작은 칼은 중앙 1920×1080을 960 입력으로 축소했을 때 박스 짧은 변이 16px 미만인 경우다. IoU 0.5로 정답과 매칭했다. 음성 프레임 오탐 상한은 100장당 1장으로 두고, 해당 범위에서 작은 칼을 가장 많이 검출하는 confidence를 **세션별**로 선택했다. 양성 프레임의 불일치 박스도 전체 오탐 박스에 포함된다.
- 기준은 기존 혼합 YOLO26n `c6e5244f649de9722c956e0c861e98975c4334e08cdd9c0a6a74dd53f0e28d0a`의 960 입력이다. 모든 크롭·타일의 칼 검출에 같은 가중치의 640 입력을 사용했다. Pose는 YOLO26n-pose·960, person confidence ≥0.20, 최대 네 사람, 손목 confidence ≥0.27이다. 사람 박스는 확장하고 손목 크롭은 손목–팔꿈치 방향으로 중심을 옮겼다. 자른 경계에 걸린 박스는 제거한 뒤 원래 좌표로 복원, IoU 0.55 NMS를 적용했다. 전체 화면과 합칠 때 크롭 점수에 0.85를 곱했다.
- 타일은 768×640 크기 6개다. 왼쪽 좌표는 0/576/1152, 위쪽 좌표는 0/440이다. 정답은 점수와 크롭의 커버리지를 계산할 때만 사용했다.
- 시간 결합은 현재 후보 confidence ≥0.01과 직전 2.2초 안의 confidence ≥0.02 후보 사이에서 크기 비 0.5–2와 중심 거리 ≤0.55×최대 박스 변을 확인한다. 점수 상향은 현재 점수와 매칭 과거 점수의 기하평균이 높을 때 적용했다. 지지 없는 후보를 낮추는 조건은 매칭 시 현재 65%와 과거 최대 35%, 미매칭 시 현재 60%를 사용했다. 미래 프레임과 영상 간 비교는 사용하지 않았다.

## 첨부안 판단과 후속 실험

| 아이디어 | 판단 |
| --- | --- |
| 수동 광학 줌 | 우선 실험한다. P430은 5배 광학 줌을 지원한다. 칼이 차지하는 센서 픽셀 수와 음성 오탐을 직접 비교할 수 있다. 좁아진 화각의 관측 범위를 함께 기록한다. 자동 줌 제어는 수동 효과와 지연을 측정한 뒤 판단한다. [Reolink P430 사양](https://reolink.com/us/product/p430/) |
| 연속 프레임 결합 | 조건부로 남긴다. 이 실험은 약 1초 간격 검출 점수 결합이다. 원본 인접 프레임의 영상 정렬 및 비생성적 결합은 독립 실험이다. 밝기·가림·움직임이 다른 장면을 포함하고, 칼과 배경을 정렬하는 과정에서 잘못 생긴 윤곽을 따로 확인한다. [연속 영상의 시간 문맥 활용 연구](https://www.mdpi.com/1424-8220/24/22/7387) |
| 손 중심 탐색 | 전역 검출을 대신하는 방식은 보류한다. 사람 주변 후보를 확보한 다음 손 단서를 Holding 분류의 보조 입력으로 쓰는 안은 남긴다. 손이 안 보이는 경우에도 사람–물체 전체 영역으로 추론할 수 있어야 한다. |
| 배경 기억 | 고정 배경의 반복 오탐이 독립 촬영에서 확인되면 후보 우선순위를 줄이는 용도로 시험한다. 정지한 사람 손의 모형까지 무시할 수 있으므로 움직임을 필수 조건으로 두지 않는다. [저해상도 감시 영상의 전경 활용 연구](https://openaccess.thecvf.com/content/WACV2026W/RWS/papers/Bouguila_FG-DINO_Inducing_Approximated_Foregrounds_into_DINO_for_Low-Resolution_Surveillance_Videos_WACVW_2026_paper.pdf) |
| 약한 검출 누적 | 약한 점수 상향을 후속 후보로 남긴다. 타일과 결합했을 때 작은 칼 검출은 늘지 않았다. 동일 경보 규칙을 사용한 연속 영상에서 오경보와 사건 시작 후 지연을 먼저 확인한다. |
| 오프라인 교사 앙상블 | 후보 제안과 놓친 박스 탐색에 쓴다. 같은 장면에서 여러 모델이 동의해도 소지 정답은 따로 확인한다. 반복 가능한 개선이 확인된 뒤 경량화와 증류를 비교한다. |
| 조건을 맞춘 대조 촬영 | 광학 줌과 함께 우선한다. 같은 사람·위치·조명에서 안전 모형을 손에 든 경우, 모형을 옆에 둔 경우, 휴대폰을 든 경우, 빈손을 묶어 촬영한다. 학습·개발 검증·최종 평가에 같은 촬영 묶음이 나뉘어 들어가지 않도록 한다. |

광학 줌 파일럿에서는 **1×·3×·5×**를 시작값으로 두고, 모형을 든 경우와 세 대조 조건에서 박스 짧은 변 픽셀과 검출률을 잰다. 카메라 위치와 사람 위치를 유지하고 관심 구역의 화각 손실을 기록한다. 칼 박스와 함께 소지한 사람의 관계 정답을 [HOI 관계 라벨 규격](../../../docs/hoi-annotation-contract.md)으로 남긴다. 손이 비거나 물체가 가까이 있지만 소지하지 않은 경우를 포함한다. 이후 동일 detector를 쓰는 B0~B4를 동결하고 새 세션에서 사건 재현율·오경보·지연을 측정한다.

## 검증 범위와 재현 기록

기존 선택점의 정검출·오탐 재계산과 PC 간 정답·예측 식별자 및 가중치 해시 대조를 마쳤다. RTX 3060, Python 3.12.4, PyTorch 2.6.0+cu124, Ultralytics 8.4.152를 사용했다. 예측 정규화와 평가 동작은 두 PC에서 동일하며 PC12의 평가기 사본에는 사용하지 않은 앙상블 함수가 추가돼 있다. 로컬 검사는 박스 평가 7개, 후보 비교 10개 중 7개 통과이며 선택 의존성이 필요한 3개를 건너뛰었다. PC12·13의 실제 결과에는 COCO AP를 계산했다.
