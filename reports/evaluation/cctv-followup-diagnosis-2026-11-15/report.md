## CCTV 전용 6개 진단

- **라벨 변환:** PC13 학습 시점의 DB 스냅샷에서 프레임 최신 판정과 CCTV 구간 승인 범위를 1,406장 전부 대조했다. 양성 161장·박스 165개, 음성 1,245장에 저장된 이미지/라벨 SHA와 픽셀 크기가 일치했다. class 0과 YOLO 좌표 변환 후 원래 좌표의 차이는 최대 0.000000096px였다. 양성 중 82장은 모델 제안 없이 박스를 추가했고, 60장은 제안과 다른 박스, 19장은 제안과 같은 박스였다. 음성 중 419장에는 초기 모델 제안이 있었다. 음성 후보에서 실제 칼이 누락됐는지는 전수 시각 확인하지 않았다. [라벨 통계](label-audit.json)
- **라벨 및 장면 품질:** 박스 크기별로 뽑은 양성 24장의 녹색 GT 박스와 주변을 확인했다. 칼이 식별되는 장면이 있었고, 조리 근접 장면, 자막·화면 합성, 저화질로 칼 경계가 모호하거나 손·주변이 크게 들어간 박스도 있었다. 이 표본으로 전체 라벨 오류율을 추정하지 않았다.
- **전처리:** 격리된 학습 이미지 13개에 대해 실제 Ultralytics 데이터로더에 증강 없이 넣어 640·960 letterbox 결과와 독립 계산을 대조했다. class 0과 입력 크기가 일치했고 변환 후 좌표 차이는 최대 0.00010px 미만이었다. 이 검사는 확률적 증강의 전체 실행 경로를 포함하지 않는다. 이전 학습 이관 때 세 노드의 데이터 해시를 확인했다.
- **학습·체크포인트:** 6개 모두 YOLO26n COCO 초기 가중치에서 612/708 항목을 가져왔고 50 epoch의 결과 행과 체크포인트가 있었다. 로그에 손상된 학습 항목 0건, CUDA OOM·Traceback 없음. 전체와 음성 축소 조건에서 양성 장수는 161, 음성은 각각 1,245 및 483이었다. 공통 검증셋의 mAP50은 0~0.0132%였다. PC11 기존 증강 전체·PC12 CCTV 증강 전체는 마지막 체크포인트의 708개 텐서가 best와 동일해, 적어도 두 조건의 실패를 best 선택만으로 설명할 수 없다.
- **크기와 장면 차이:** 640 입력 기준 학습 박스 짧은 변의 중앙값은 24.0px, 실제 CCTV 평가 박스는 9.70px이다. 16px 미만은 각각 33/165, 26/31이다. 양성 학습은 67개 영상 해시 그룹에 걸쳐 있었다. 다른 편집본은 별도 영상 해시일 수 있다.

## 다음 학습 우선순위

1. **기존 S1 체크포인트에서 짧게 혼합 파인튜닝.** 기존 실사 양성/배경을 유지하고 선별한 CCTV 양성과 음성을 영상 그룹별로 섞는다. 같은 초기 가중치·업데이트 예산의 대조군을 만들고, 초기 실험의 해상도는 고정한다. 양성 혼합 비율과 약한 증강 조건을 기록한다. 기존 CNN의 칼 검출 능력을 활용하며 이 조합의 이득을 측정할 수 있다. [Ultralytics 파인튜닝 안내](https://docs.ultralytics.com/guides/finetuning-guide)
2. **실패 구간과 비슷한 양성 선별·박스 재검수.** 640 입력에서 작은 칼을 담은 프레임을 먼저 확인하며, 조리/편집 화면과 칼 식별 불가 박스는 우선 보류한다. 배경은 검수 음성 중 혼합 모델이 실제 오탐한 프레임에서 뽑는다. 초기 모델 칼 제안이 있었던 음성 419장을 우선 살피되, 최근 모델의 점수와 실제 칼 부재를 재확인한다. 음성 선별 효과는 음성 장수와 업데이트를 맞춰 비교한다.
3. **부분 이미지 비교.** 학습 영상에서 칼 주변 문맥을 포함한 타일과 전체 장면을 함께 학습하고, 별도 튜닝 영상에서 평가 정답을 쓰지 않는 겹침 타일 추론과 960 전체 추론을 비교한다. 원본 좌표 복원과 중복 박스 통합, 오탐과 Orin 지연을 확인한다. 같은 영상에서 잘라낸 타일은 한 split에 둔다. [SAHI 원 논문](https://arxiv.org/abs/2202.06934)
