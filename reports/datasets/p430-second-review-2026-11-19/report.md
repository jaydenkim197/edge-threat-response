## 박스 생성기 선택

PC13 RTX 3060 12GB / PyTorch 2.6.0+cu124 / Transformers 5.22.1에서 **동일한 시간 균등 표본 24장**을 비교했다. 프로젝트의 custom weight는 사용하지 않았다.

| 후보 | 실행·관찰 |
| --- | --- |
| Grounding DINO Base | 전체+타일 24장 실행. 바닥 X자 테이프와 일부 사람·책상까지 칼로 제안하는 오류 관찰 |
| OWLv2 Large ensemble | 전체+타일 24장 실행. 책상 위 칼의 연속 표본을 검출. 혼동 물체 대조 쿼리도 별도 실행 |
| RF-DETR Large (COCO) | 같은 24장 실행. 전체+타일 11.0초. 여러 책상 위 칼 표본 누락 관찰 |
| YOLO26x (COCO) | 같은 24장, 입력 1280. 전체+타일 21.9초. 제안이 적어 주력 초안으로 선택하지 않음 |

선택은 **OWLv2 Large + 혼동 물체 대조 쿼리**, 제안 threshold 0.15다. `a knife` / `a toy knife`를 칼 후보로 하고, 리모컨·휴대폰·물병·바닥 테이프·사람·책상을 경쟁 클래스로 함께 넣는다. 표본에서 반복적인 바닥 테이프 오탐을 줄이면서 책상 위 칼 제안을 유지했다. 이는 AI 보조 표본 점검에 따른 라벨링용 선택이며 수동 GT에 대한 정식 정확도나 세계 최고 모델임을 검증한 결과가 아니다.

## 코드·검증

기존 `prepare_capture_review.existing_frames`와 `prepare_team_review.write_pack`, 박스 IoU, preview 생성기와 웹 배정·저장 경로를 재사용했다. `tools/prepare_foundation_capture_review.py`는 외부 detector의 offline proposal과 새 세션 팩 생성을 담당한다. 기존 팩을 덮어쓰지 않는다.

관련 단위 테스트 6개(새 4개+기존 capture 2개), compileall과 diff 검사를 통과했다. 390×844 Chromium의 **격리 DB**에서 실제 4K 표본 3장으로 무코드 입장, 중앙/전체 전환, 터치 박스 추가와 원본 좌표 저장, 기존 제안 확인, 새로고침 후 이어가기, 칼 없음 저장을 검증했다. 운영 DB에는 테스트 판정을 쓰지 않았다. 실제 iOS/Android 물리 장치 검증과 전체 팩 운영 등록은 아직 별도다.
