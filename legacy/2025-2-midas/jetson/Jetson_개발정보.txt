7. Jetson 쪽 코드 작성 시 “필수 규칙” 정리

팀원이 Jetson 용 추론 코드를 개발할 때 반드시 지켜야 할 것들:

import 순서

import cv2
import torch


이 순서 지키지 않으면 TLS 에러로 죽음:

/usr/lib/aarch64-linux-gnu/libgomp.so.1: cannot allocate memory in static TLS block

pandas / matplotlib / seaborn 절대 사용 금지

numpy 1.13.3 환경이라 현대 pandas와 호환 안 됨

YOLOv5 내부에서도 pandas import하는 부분은 전부 try/except + pd = None + if pd is not None: 처리 필요

ultralytics(최신 패키지) 사용 금지

Python 3.6 + Jetson 환경에서 설치/의존성 맞추기 거의 불가능

반드시 “로컬에서 ultralytics로 학습 → Jetson에서는 순수 YOLOv5 repo로 inference만 수행” 구조로 가야 함

모델 사이즈 / 연산량

yolov5n 기준으로 네트워크 설계 및 훈련

헤드나 블록을 무식하게 늘리면 Nano에서는 추론이 안 돌아가거나 FPS 0.x 수준 될 수 있음

Python 3.6 호환성

f-string은 가능하지만,

3.7 이상 문법/라이브러리 사용 금지
(팀원이 trainer 쪽 코드 따로 짤 땐 상관 없지만, Nano에 올라오는 inference 코드만큼은 3.6 기준 맞춰야 함)
