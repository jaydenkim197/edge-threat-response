MIDAS Project – 최종 활동 정리(txt 완성본)

(프로그램 제출·포트폴리오·보고서·기업 지원용 통합 버전)

1. 프로젝트 개요

본 프로젝트는 “AI 기반 실시간 흉기 탐지 및 위험 상황 자동 알림 시스템” 구축을 목표로 진행되었다.
Jetson Nano 엣지 디바이스에서 YOLO 기반 커스텀 흉기 탐지 모델을 실시간으로 실행하고, 탐지 결과에 따라 LED 및 부저를 즉시 활성화하며, WebSocket 기반 웹 UI로 영상을 전송하는 통합 지능형 보안 시스템을 구현하였다.

팀은 전자공학·정보통신공학·시각디자인 전공으로 구성되어 SW–HW–디자인 전 영역을 융합한 형태로 진행되었다.
그중 나는 Jetson Nano 기반 전체 시스템 통합 엔지니어로서 SW–HW–AI–UI를 단일 파이프라인으로 연결하는 핵심 역할을 맡았다.

2. 본인의 역할 요약: “Jetson 기반 시스템 통합 엔지니어”

프로젝트 전 과정에서 다음과 같이 전체 시스템의 기술적 연결을 담당하였다.

2-1. Jetson Nano 플랫폼 구축

JetPack 4.6.3(L4T 32.7.6) 기반 Ubuntu 18.04 환경 세팅

Python 3.6 기반 저호환성 문제 해결(numpy 1.13, pandas 미지원 등)

YOLOv5 v6.0 기반 커스텀 추론 환경 구성

torch 1.8.0(aarch64) + torchvision 0.8.2 빌드

OpenCV–torch import 순서 문제, libgomp 오류 해결

외장 USB(ext4) 마운트 후 전체 개발 환경 이전(저장 공간 부족 해소)

2-2. 실시간 추론 엔진 개발

OpenCV 기반 실시간 프레임 처리 구조 구축

YOLO 모델 로딩(attempt_load), CPU map_location 환경 대응

non_max_suppression → bbox 추출 → 렌더링 파이프라인 구성

Jetson Nano 성능을 고려한 경량·최적화된 추론 루프 개발

2-3. 하드웨어 제어 모듈 구성

LED, Buzzer GPIO 회로 직접 설계

Jetson.GPIO 사용한 실시간 위험 알림 제어

탐지 이벤트 발생 시 즉시 하드웨어 경보 출력

2-4. 실시간 Web UI 연동

WebSocket 기반 프레임 송출 서버(FastAPI) 구축

JPEG 인코딩 후 스트리밍 성능 최적화

UI/디자인 팀과의 협업을 통해 “위험도 시각화” 구조 정의

Jetson–웹 UI 간 end-to-end 데이터 흐름 안정화

2-5. 데이터·모델 개선 지원

긴 형태의 철골·파이프류가 칼로 오탐되는 문제 발견

이를 위한 추가 클래스 데이터셋 구축 및 모델 성능 향상 기여

→ 위 역할을 기반으로 최종적으로 “AI 모델 + Jetson 추론 엔진 + HW 제어 + Web UI 스트리밍”이 하나로 연결된 완전한 통합 시스템을 구축했다.

3. 프로젝트 핵심 시스템 구조

전체 시스템은 다음 세 영역으로 구성되며 Jetson이 중심 노드 역할을 수행한다.

3-1. AI 추론 시스템

Jetson Nano에서 YOLO 커스텀 모델 실시간 실행

모델 출력 기반 위험도 계산 및 객체 경계 상자 생성

모델 정확도 향상을 위해 클래스 추가 및 오탐 제거 전략 사용

3-2. HW 제어 시스템

LED·Buzzer 기반 위험 상황 알림

GPIO 레벨에서 즉각적 신호 제어

실제 비상상황 대응용 하드웨어 구조 실험 완료

3-3. UI·스트리밍 시스템

WebSocket을 통해 Jetson에서 실시간 영상 전송

브라우저에서 Canvas로 디코딩 및 위험도 표기

사용자 확인을 위한 실시간 모니터링 인터페이스 구축

4. Jetson 환경에서 해결한 기술적 도전

Jetson Nano는 Python 3.6, CUDA 10.2, numpy 1.13 등 최신 AI 라이브러리와 높은 비호환성을 갖는다.
이를 해결하기 위해 다음 조치를 수행하였다.

최신 ultralytics YOLO 불가 → v5/v6 커스텀 버전 사용

torch 호환 wheel 직접 설치

torchvision aarch64 빌드

import 순서 문제로 발생하는 CUDA TLS 오류 해결

cv2·torch·numpy 버전 충돌 해결

외장 저장소 사용한 전체 개발 환경 재구축

Jetson에서 발생하는 Video4Linux, gst-launch 연결 문제 해결

/dev/video0 읽기 오류, MJPG 포맷 대응, 프레임 버퍼 최적화 처리

Jetson 환경은 매우 제한적이었으나, 모든 오류를 해결하며 실제로 작동하는 AI 기반 엣지 시스템을 구현했다.

7. 결론

본 프로젝트는 Edge AI–HW 제어–Web UI를 결합한 완전한 통합 보안 시스템 프로토타입 구현을 목표로 했으며, Jetson 기반 제약 환경에서도 실시간 흉기 탐지–경보–UI 연동을 모두 성공적으로 수행하였다.
특히 Jetson 환경 최적화, AI 모델 이식, 하드웨어 제어, 실시간 스트리밍 서버 구축까지 일련의 기술적 흐름을 통합한 경험은, 실제 산업에서 요구되는 임베디드 AI 엔지니어링 역량과 동일한 수준의 복합 기술 수행 능력을 보여준다.

본인은 이 프로젝트에서 전체 시스템 통합 엔지니어로서 핵심 기술 구조를 직접 설계·구현하였고, Jetson 기반 실시간 AI 시스템 구축 전 과정을 경험하였다.
